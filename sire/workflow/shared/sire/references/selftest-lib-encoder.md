## 一、怎么用这份库

| 类 | 含义 | 自测时 |
| --- | --- | --- |
| **必测（外部版）** | 外部版用户能看到、能用的功能（下面 A～I 组） | 每次提测全部要测 |
| **必测（本次）** | 本次提测内容里特意说明的新增 / 修改功能（含 `【算法】` 项） | 从提测内容里挑出来加进自测报告 |
| 可不测 | 仅内部版 / 仅 HTTP 工具（第三节） | 报告里标"否（原因）"，不测不算缺项；本次改到就升为必测 |

列说明：**型号**见 4.12.0 报告的写法（DPT、DPB、DPT-G1、MPT、MPP 等）；**写设备** = 会改编码器里的数据，需授权单"允许写设备"；标定类要**转动编码器**，需要人在场或有转台，没有就如实写"待测"。每种型号至少测一台，没有的型号写"待测"，不当通过。
