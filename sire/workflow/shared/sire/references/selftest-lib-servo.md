## 一、怎么用这份库

| 类 | 含义 | 自测时 |
| --- | --- | --- |
| **必测（L0）** | 客户版 L0 能看到、能用的功能（下面 A～H 组） | **每次提测全部要测** |
| **必测（本次）** | 本次提测内容里特意说明的新增 / 修改功能，不论属于哪一档 | 每次从提测内容里挑出来，加进自测报告 |
| 可不测 | L1 及以上才有的功能（第三节） | 报告里标"未测（非必测）"；本次提测内容改到它就升为"必测（本次）" |

列说明：**设备** = 要不要连真实舵机；**写设备/风险** = 是否改设备配置、让电机转动。有"转"的项需要授权单上"允许真机自测"，有"写"的项需要"允许写设备"，**写 Flash / 固件升级永远另问**。

## 三、可不测（L1 及以上，非外部版）

提测内容改到哪一项，那一项升为"必测（本次）"。

| 档 | 功能 |
| --- | --- |
| L1 | 「轨迹」页（CSV 导入、分通道编辑、协议回放、meas 叠加）；运动页「附加寄存器」；运动页多设备采集；连接抽屉「是否连接多个设备」；顶栏协议档案下拉（L0 只读显示）；故障面板内部故障位 |

| L3 | 「寄存器」页；「控制台」页；「测试套件」页（含一键空载回归）；「诊断」页（黑匣子配置）；示波器抽屉「测试波形」 |
