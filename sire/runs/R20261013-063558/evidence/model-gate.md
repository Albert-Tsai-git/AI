# 模型选择门禁（R4 放行后、R5 执行前）

Qoder 客户端的 Agent 工具不暴露 `model` 参数，只有 `subagent_type`（见用户长期记忆 `sire-resource-locations`），
因此"低难度派 haiku/sire-low"的降级路径在本客户端走不通，机械可核对的部分已尽量派给只读 Explore 子代理，
模型档位只能记为"主控直接执行"。派工记录见各单元 note。

| 单元 | 难度 | 执行者 | 判定理由 |
|---|---|---|---|
| 前置勘察 ×4（后端 / 前端 / 工程基建 / 文档与在研） | 低-中 | Explore 子代理 ×4 并行 | 批量读文件与搜代码，只读、无设计决策，可并行且读写集不冲突 |
| R4 计划复核 ×2 | 高 | general-purpose 子代理（独立） | 作者不能自审；需按机制源码判可测性与重叠 |
| U-01 后端通信链记录 | 中 | 主控 | 跨 8 个 core 文件的事实归并，需判断详略与行号取舍 |
| U-02 协议与档案记录 | 中 | 主控 | 需把协议文档差异、档案门控行为、新增命令链路合成为一条可检索记录 |
| U-03 前端记录 | 中 | 主控 | 13 页清单 + 5 处注册点 + 图表/节流坑，取舍属设计判断 |
| U-04 Electron 记录 | 低 | 主控 | 单一文件的装配事实，机械可核对；与 U-05 的归属边界由主控裁定（归 U-05） |
| U-05 构建/测试/CI 记录 | 中 | 主控 | 三个子系统合一，需与 F-019/F-024 划清"原则 vs 落地事实" |
| U-06 下线检测记录 | 中 | 主控 | 在研功能，状态必须与 CHANGELOG 与 commit 对齐，误写即误导后续开发 |
| U-07 文档与协作记录 | 中 | 主控 | 含"AGENTS.md 引用不实"结论，需自行复核不能照抄子代理 |
| U-08 索引与校验 | 低 | 主控 | 三条既有命令 + 两条断言，机械执行 |
| U-09 检索验收 | 中 | 主控 + 独立复核 | 最终裁决不降级；命中判定为机械断言 |

结论：本轮无可降档派发空间（写库/裁决类保留主控，只读勘察已外派）；按契约第 4 条，纯单点任务不为派工而派工。
